# Test C Project

A simple C language test project with standard directory structure.

## Project Structure

```
test/
├── src/           # Source files (.c)
├── include/       # Header files (.h)
├── lib/           # Library files
├── tests/         # Test files
├── docs/          # Documentation
├── examples/      # Example code
└── build/         # Build output (generated)
```

## Build Instructions

```bash
# Clone the repository
git clone https://github.com/Lion2c/test.git
cd test

# Build the project
make

# Run the program
make run

# Clean build files
make clean
```

## Example Usage

1. Add source files to `src/` directory
2. Add header files to `include/` directory
3. Run `make` to build
4. Run `make run` to execute

## Dependencies

- GCC compiler
- Make
